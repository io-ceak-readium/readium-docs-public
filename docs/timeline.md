# Timeline

Timeline은 Readium에 기록된 활동을 시간순으로 확인하는 화면입니다.

단순한 책 목록이 아니라, 언제 읽기 시작했고 언제 끝냈고 어떤 메모를 남겼는지를 다시 보는 데 초점이 있습니다.

![Timeline 화면](/img/005-timeline.jpg)

## 기록되는 활동

- 세션 시작
- 세션 종료
- 완독
- 중단
- 책 노트 작성
- 세션 노트 작성

## 타임라인에서 할 수 있는 일

- 최신 활동부터 확인
- 키워드 검색
- 숨김 책 이벤트 포함 여부 전환
- 이벤트에서 연결된 책 상세 열기
- 노트 이벤트에서 노트 상세 열기

## 검색

오른쪽 상단 검색 버튼으로 검색 모드를 켜면 키워드를 입력해 현재 타임라인을 좁혀 볼 수 있습니다. 검색을 종료하면 첫 페이지로 돌아갑니다.

## 숨김 책 이벤트 보기

숨김 처리된 책의 이벤트를 포함해서 볼지 선택할 수 있습니다. 서재의 숨김 보기 토글과 비슷하지만 타임라인 화면에서 별도로 제어합니다.

## 페이지 이동

타임라인은 페이지 단위로 로드되며, 하단 이전/다음 버튼으로 이동합니다.

## 언제 보면 좋은가

타임라인은 다음 상황에서 특히 유용합니다.

- 최근 어떤 책을 읽었는지 기억이 안 날 때
- 특정 날 남긴 메모를 다시 찾고 싶을 때
- 완독과 중단 시점을 돌아보고 싶을 때
