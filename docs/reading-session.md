# Reading Session

세션은 “실제로 읽은 시간”입니다.

완독 여부보다 중요한 것은  
읽은 순간의 기록입니다.

---

## 세션 시작

버튼을 누르면 기록이 시작됩니다.

동시에 두 개의 세션은 실행되지 않습니다.

---

## 세션 종료

버튼을 누르면 시간이 저장됩니다.  
그날의 생각을 짧게 남길 수도 있습니다.

---

## 왜 세션인가요?

독서는 하루에 끝나지 않습니다.

세션 기록은  
당신의 독서 리듬을 보여줍니다.
