# Reading Session

Readium의 핵심은 **세션(Session)** 입니다.

---

## 세션 시작

- “세션 시작” 버튼을 누르면
- 하나의 Session ID가 생성됩니다.
- 타임라인에 SESSION_STARTED 이벤트가 기록됩니다.

---

## 세션 종료

- “세션 종료” 버튼 클릭
- 종료 시간 기록
- 필요 시 세션 노트 작성
- SESSION_ENDED 이벤트 기록

---

## 왜 세션 중심인가?

일반 독서 앱은 “완독 여부”만 남깁니다.

Readium은:

- 언제 읽었는지
- 얼마나 읽었는지
- 어떤 생각을 했는지

를 시간 흐름 단위로 남깁니다.

---

## 중복 세션 방지

- 동시에 두 개의 활성 세션은 존재하지 않습니다.
- 이미 활성 세션이 있으면 시작 대신 종료 동작이 수행됩니다.
