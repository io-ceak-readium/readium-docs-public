# Reading Session

세션은 Readium에서 실제로 읽은 시간을 기록하는 기본 단위입니다.

한 권의 책을 여러 번 나눠 읽더라도 세션이 계속 누적되어 독서 흐름을 남깁니다.

## 세션 시작

세션은 두 곳에서 시작할 수 있습니다.

- `책 상세 화면`
- `Now Reading` 탭

어느 화면에서 시작하든 기록 규칙은 같습니다.

## 세션 종료

세션을 끝낼 때는 진행률을 입력합니다.

- 최근 종료 진행률을 기본값으로 불러올 수 있음
- 1분 이상 읽은 세션만 정상 기록
- 종료 후 세션 노트 작성 가능

## 짧은 세션 처리

세션 시작 후 1분이 지나지 않은 상태에서 종료하면 기록이 저장되지 않을 수 있습니다. 앱은 이런 경우 매우 짧은 세션으로 보고 별도 안내를 표시합니다.

## 완독과 세션 종료의 차이

진행률을 `100%`로 입력하면 일반 종료가 아니라 완독 처리로 이어집니다.

- 완료 이벤트가 기록됨
- 책 노트 작성을 제안받을 수 있음

반대로 `100% 미만`이면 세션만 종료되고 세션 노트를 작성하는 흐름으로 이어집니다.

## 이 문서와 Now Reading 문서의 차이

이 문서는 세션이 저장되는 방식과 종료 규칙을 설명합니다.

- 세션 기능 자체의 규칙이 궁금하면 이 문서
- 현재 읽는 책 화면에서 어떤 버튼이 보이고 어떻게 빠르게 조작하는지가 궁금하면 `Now Reading` 문서
