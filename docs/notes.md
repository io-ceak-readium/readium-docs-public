# Notes

Readium에는 두 종류의 노트가 있습니다.

---

## 1. Book Note

- 책 전체에 대한 노트
- 완독 후 정리용으로 사용 가능

---

## 2. Session Note

- 특정 세션 종료 시 작성
- 읽은 구간에 대한 즉시 기록

---

## 노트 편집

- 노트 상세 화면에서 복사 가능
- 편집 기능은 지원 버전에 따라 다를 수 있습니다.

---

## 타임라인 연동

세션 노트는 타임라인 이벤트와 연결되어  
나중에 읽기 흐름과 함께 회고할 수 있습니다.
