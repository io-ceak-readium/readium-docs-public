# Notes

Readium의 노트는 책 전체 메모와 읽은 순간의 메모를 분리해서 관리합니다.

![Notes 화면](/img/004-notes.jpg)

## 노트 종류

- `책 노트`: 책 전체 감상, 정리, 요약
- `세션 노트`: 특정 읽기 시간에 대한 메모

## 책 노트 작성

책 노트는 보통 다음 흐름에서 작성합니다.

- 책 상세 화면에서 직접 작성
- 완독 후 제안 시트에서 바로 작성
- 중단 후 제안 시트에서 바로 작성

## 세션 노트 작성

세션 노트는 보통 다음 흐름에서 작성합니다.

- 세션 종료 직후
- `Now Reading`에서 빠른 메모 추가
- 기존 세션 노트 열기 후 수정

## 편집 방식

노트는 리치 텍스트 편집기를 사용합니다. 저장 버튼은 내용이 비어 있지 않을 때만 활성화됩니다.

## 노트 보기와 수정

책 상세의 `Notes` 탭에서 책 노트와 세션 노트를 각각 확인할 수 있습니다. 노트 상세 시트에서는 내용을 열람하고 수정할 수 있습니다.

## 저장 실패 시

저장에 실패하면 시트가 실패 상태로 닫히거나 오류 메시지가 표시될 수 있습니다. 중요한 내용은 네트워크가 아니라 로컬 저장 흐름의 문제일 가능성이 크므로 다시 시도하면 됩니다.
