# 책 추가와 검색

Readium은 현재 서재에 책을 추가할 때 외부 도서 검색 흐름을 사용합니다.

## 검색 화면 진입

`Library` 오른쪽 상단 `+` 버튼을 누르면 검색 화면이 열립니다.

## 검색 방법

다음 세 가지 방식이 구현되어 있습니다.

- 키워드 검색: 제목, 저자 등으로 검색
- ISBN 검색: 숫자를 직접 입력
- 바코드 스캔: 카메라로 ISBN 코드 인식

ISBN 형식으로 판단되면 일반 검색보다 ISBN 조회를 먼저 시도합니다.

## 페이지 이동

검색 결과는 한 번에 일부만 표시되고, 이전/다음 버튼으로 페이지를 넘길 수 있습니다.

## 중복 책 처리

이미 서재에 있는 책과 동일하거나 매우 유사한 책이 감지되면 앱이 다음 중 하나를 제안할 수 있습니다.

- 취소
- 기존 책 열기
- 그래도 추가

완전히 같은 책으로 판단되면 중복 추가 대신 기존 상세 화면으로 이동합니다.

## 바코드 스캔

스캔 화면에서는 다음 동작을 지원합니다.

- ISBN-13 인식
- UPC-A를 EAN-13 형식으로 보정
- 플래시 켜기/끄기

지원되지 않는 코드면 안내 메시지만 보여 주고 스캐너는 계속 유지됩니다.
