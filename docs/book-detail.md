# 책 상세 화면

책 상세는 한 권의 책에 대한 모든 작업이 모이는 화면입니다.

![Book Detail 화면](/img/003-bookDetail.jpg)

## 상단에서 할 수 있는 일

- 책 제목 확인
- 책 상태 변경
- 평점 저장 또는 해제
- 숨김 여부 확인

책 상태는 칩을 눌러 바로 바꿀 수 있습니다.

## 더보기 메뉴

오른쪽 상단 메뉴에서 다음 작업을 할 수 있습니다.

- `완독 처리`
- `중단 처리`
- `서재에서 제거`
- `서재로 복원`

완독이나 중단 뒤에는 책 노트 작성을 제안하는 시트가 열릴 수 있습니다.

## 읽기 제어

숨김 책이 아니라면 상세 화면에서 읽기 관련 액션이 표시됩니다.

- 세션 시작
- 세션 종료
- 진행률 입력
- 읽는 중 상태 확인

세션 종료 시 진행률에 따라 결과가 달라집니다.

- `100%`: 책이 완독 처리됨
- `100% 미만`: 세션 종료 후 세션 노트 작성 가능

## 탭 구성

책 상세 하단에는 3개의 탭이 있습니다.

- `All`: 이 책과 관련된 전체 활동
- `Records`: 읽기 기록과 세션 중심 보기
- `Notes`: 책 노트와 세션 노트

## 노트 보기와 수정

노트 탭에서 기존 노트를 열어 상세 시트로 볼 수 있습니다. 현재 구현 기준으로 노트는 보기뿐 아니라 수정도 가능합니다.

## 숨김 책의 동작

숨김 처리된 책은 읽기 제어가 비활성화되고, 대신 숨김 상태 안내와 복원 액션이 중심이 됩니다.
