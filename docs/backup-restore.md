# 백업 및 복구

Readium의 데이터는 기본적으로 기기에 저장되므로, 기기 교체나 재설치 전에는 백업을 권장합니다.

## 설정 화면에서 할 수 있는 일

- 데이터베이스 파일 공유
- Android에서 다운로드 폴더로 백업 저장
- `.readium` 파일로 복원
- 언어 변경
- 테마 변경

## 백업 내보내기

1. Settings로 이동합니다.
2. 백업 또는 내보내기 항목을 선택합니다.
3. 생성된 파일을 공유하거나 저장합니다.
4. 안전한 외부 위치에 보관합니다.

Android에서는 다운로드 폴더에 직접 저장하는 항목이 별도로 보일 수 있습니다.

## 복원

1. Settings에서 복원 항목을 선택합니다.
2. `.readium` 파일을 고릅니다.
3. 복원 경고를 확인하고 진행합니다.
4. 복원이 끝나면 앱 재시작 안내가 표시됩니다.

복원은 현재 데이터를 대체하는 흐름이므로 실행 전에 최신 백업을 하나 더 만들어 두는 것이 안전합니다.

## 주의 사항

- 복원 파일 확장자는 `.readium` 이어야 합니다.
- 복원 후 앱 재시작이 필요합니다.
- 기존 데이터가 덮어써질 수 있습니다.
- 장기적으로는 정기 백업을 권장합니다.
