# Backup & Restore

Readium은 로컬 DB 기반 앱입니다.

데이터는 기본적으로 기기에 저장됩니다.

---

## Export

1. Settings → Export
2. `.readium` 파일 생성
3. 외부 저장소 또는 클라우드로 보관

---

## Import

1. Settings → Import
2. `.readium` 파일 선택
3. 데이터 복원

---

## 주의사항

- Import 시 기존 데이터가 덮어쓰일 수 있습니다.
- 반드시 최신 백업을 유지하십시오.

---

## 파일 형식

- 확장자: `.readium`
- 내부적으로 SQLite 데이터 기반
