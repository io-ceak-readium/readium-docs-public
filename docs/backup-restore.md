# 백업 및 복구

Readium은 기본적으로 데이터를 기기에 저장합니다.

기기 변경이나 재설치를 대비해 백업을 권장합니다.

---

## 백업 (Export)

1. Settings로 이동합니다.
2. Export를 선택합니다.
3. `.readium` 파일이 생성됩니다.
4. 외부 저장소에 보관합니다.

---

## 복구 (Import)

1. Settings → Import
2. 백업 파일 선택
3. 데이터 복원

---

## 주의 사항

- Import 시 기존 데이터가 덮어질 수 있습니다.
- 정기적인 백업을 권장합니다.
