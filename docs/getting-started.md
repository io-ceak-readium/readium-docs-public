# 시작하기

Readium은 계정 생성이나 복잡한 초기 설정 없이 바로 사용할 수 있습니다. 처음 사용할 때는 아래 순서로 익히는 것이 가장 빠릅니다.

## 1. 서재에서 책 추가

하단 탭에서 `Library`를 열고 오른쪽 상단 `+` 버튼을 누릅니다.

검색 화면에서 할 수 있는 일:

- 제목이나 저자명으로 외부 도서 검색
- ISBN 직접 입력
- 바코드 스캔으로 ISBN 검색

검색 결과에서 원하는 책을 고르면 서재에 추가됩니다. 추가 직후에는 책의 소장 상태를 선택할 수 있습니다.

## 2. 책 상세 확인

서재 목록에서 책을 누르면 상세 화면으로 이동합니다. 상세 화면에서는 다음 작업을 할 수 있습니다.

- 책 상태 변경
- 평점 저장 또는 해제
- 읽기 시작과 종료
- 완독 또는 중단 처리
- 책 노트와 세션 노트 확인

## 3. 읽기 시작

세션은 책 상세 화면이나 `Now Reading` 탭에서 시작할 수 있습니다.

세션을 시작하면 읽은 시간이 측정되고, 현재 읽는 책은 `Now Reading` 탭에 표시됩니다.

## 4. 읽기 종료

세션 종료 시에는 진행률을 입력합니다.

- `100%`를 입력하면 책이 완독 처리됩니다.
- `100% 미만`이면 세션만 종료되고 세션 노트를 작성할 수 있습니다.
- 1분 미만의 매우 짧은 세션은 기록으로 남지 않을 수 있습니다.

## 5. 기록 확인

독서가 끝난 뒤에는 두 곳을 보면 됩니다.

- `Timeline`: 언제 무엇을 했는지 확인
- `Stats`: 누적 독서 시간과 최근 7일 읽기량 확인

## 6. 백업

데이터는 로컬 저장이 기본이므로 중요한 기록은 `Settings`에서 `.readium` 백업 파일로 저장해 두는 것이 안전합니다.
