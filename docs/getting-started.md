# Getting Started

Readium은 **세션 중심 리딩 로그 앱**입니다.  
책을 단순히 등록하는 것이 아니라, “읽는 시간의 흐름”을 기록합니다.

---

## 1. 앱 설치

- Android: APK 또는 스토어 배포 버전 설치
- 최초 실행 시 로컬 DB가 자동 생성됩니다.

---

## 2. 첫 책 추가

1. Library 화면으로 이동
2. “책 추가” 선택
3. 직접 입력 또는 Catalog 검색(지원 시)
4. 저장

이제 해당 책은 Library에 등록됩니다.

---

## 3. 읽기 시작

1. Book Detail 화면으로 이동
2. “세션 시작” 버튼 터치
3. 상태가 “읽는 중”으로 변경됨

이 시점부터 하나의 Reading Session이 시작됩니다.

---

## 4. 읽기 종료

1. “세션 종료” 버튼 터치
2. 필요 시 세션 노트 작성
3. 타임라인에 이벤트 생성

이렇게 Readium은 읽기 흐름을 시간 순서대로 축적합니다.
