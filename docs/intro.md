# Readium

당신의 독서를 **시간으로 남기는 리딩 로그 앱**.

Readium은 단순히 책을 기록하는 앱이 아닙니다.  
읽은 순간을 세션으로 남기고,  
그 흐름을 타임라인으로 다시 꺼내볼 수 있도록 설계되었습니다.

![Library 화면](/img/screenshots/intro_library.jpg)

---

## Readium의 특징

### ⏱ 세션 중심 기록

읽기를 시작하고 종료하면  
그 시간이 자동으로 저장됩니다.

“얼마나 읽었는지”가 아니라  
“언제, 어떻게 읽었는지”를 남깁니다.

![Book Detail - 세션 버튼](/img/screenshots/intro_book_detail.jpg)

---

### 🗂 타임라인 기반 정리

- 세션 시작
- 세션 종료
- 완독
- 노트 작성

모든 활동이 시간 순서대로 정리됩니다.  
독서의 흐름을 한눈에 볼 수 있습니다.

![Timeline 화면](/img/screenshots/intro_timeline.jpg)

---

### 📝 간결한 노트

- 책 전체 노트
- 세션별 노트

필요한 만큼만 기록하세요.  
과한 기능은 넣지 않았습니다.

![노트 작성 화면](/img/screenshots/intro_note.jpg)

---

### 💾 로컬 중심 데이터

읽기 기록과 노트는 기본적으로 **기기에 저장**됩니다.

앱은 Firebase 익명 인증과 Google AdMob을 사용하지만,  
독서 데이터는 앱 서버로 업로드되지 않습니다.

---

## 사용 흐름

1. 책을 추가합니다.
2. 읽기 세션을 시작합니다.
3. 세션을 종료합니다.
4. 타임라인에서 흐름을 확인합니다.

다음 문서에서 자세히 설명합니다.
