# Now Reading

`Now Reading`은 현재 읽는 책을 가장 빠르게 이어서 관리하는 화면입니다. 서재에서 책을 다시 찾거나 책 상세로 들어가지 않아도, 지금 읽는 책들만 모아서 바로 행동할 수 있습니다.

![Now Reading 화면](/img/002-nowReading.jpg)

## 이 화면이 언제 유용한가

다음 상황에서 가장 잘 맞습니다.

- 지금 읽고 있는 책을 바로 다시 시작하고 싶을 때
- 방금 읽은 책의 세션을 끝내고 싶을 때
- 책 상세로 들어가지 않고 세션 메모만 빨리 남기고 싶을 때
- 동시에 여러 권을 읽는 중이라 현재 진행 중 목록만 따로 보고 싶을 때

앱 시작 시 `읽는 중` 항목이 있으면 첫 화면이 `Now Reading`이 될 수 있습니다.

## 목록 구성

현재 구현 기준으로 이 화면은 다음처럼 구성됩니다.

- 가장 최근 항목 1개를 큰 카드로 표시
- 나머지 읽는 중 책은 그리드 카드로 표시
- 전체 개수와 나머지 개수를 함께 표시

빈 상태라면 `현재 읽는 책이 없다`는 안내 메시지가 나옵니다.

## 각 카드에서 할 수 있는 일

각 책 카드에서는 다음 액션을 바로 실행할 수 있습니다.

- 책 상세 열기
- 세션 시작
- 세션 종료
- 세션 노트 빠른 추가

대표 카드에는 최근 활동 시각과 마지막 진행률, 현재 세션이 진행 중일 때 경과 시간 배지도 함께 표시됩니다.

## 세션 시작과 종료

세션 토글 버튼은 현재 상태에 따라 다르게 동작합니다.

- 활성 세션이 없으면 `읽기 시작`
- 활성 세션이 있으면 `읽기 종료`

세션 종료 시에는 진행률 입력 단계가 이어집니다.

- `100%` 입력: 일반 종료가 아니라 완독 처리
- `100% 미만` 입력: 세션만 종료
- 1분 미만 세션: 정상 기록으로 남지 않을 수 있음

완독 처리 후에는 책 노트 작성을 제안할 수 있고, 일반 종료 후에는 세션 노트 작성을 제안할 수 있습니다.

## 메모 추가 버튼의 동작

이 화면의 `메모 추가`는 책 노트가 아니라 `세션 노트` 기준입니다.

중요한 점:

- 활성 세션이 이미 있으면 그 세션에 메모를 추가
- 활성 세션이 없으면 세션을 먼저 시작한 뒤 메모 작성 화면을 엶

즉, `Now Reading`의 메모는 "지금 이 읽기 시간에 대한 기록"에 더 가깝습니다.

## 책 상세와의 차이

`Book Detail`은 한 권의 책에 대한 전체 관리 화면이고, `Now Reading`은 지금 읽는 책을 빠르게 조작하는 대시보드에 가깝습니다.

다음처럼 구분하면 됩니다.

- 세부 정보, 기록, 노트 전체를 보고 싶으면 `Book Detail`
- 읽기 시작, 종료, 세션 메모만 빠르게 처리하려면 `Now Reading`

`세션` 자체의 저장 규칙과 종료 정책이 궁금하다면 `Reading Session` 문서를 함께 보면 됩니다.
