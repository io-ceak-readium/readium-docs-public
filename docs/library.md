# Library

Library는 내가 관리하는 모든 책 목록입니다.

---

## 책 추가

- 수동 입력
- Catalog 기반 검색 (지원 시)

저장 시 하나의 Library Item이 생성됩니다.

---

## 책 상태

책은 다음 상태 중 하나를 가질 수 있습니다:

- Reading
- Completed
- Stopped

### 완독 정책

- 완독 처리 시 활성 세션이 있다면 자동 종료됩니다.
- 노트 작성은 UI에서 유도되지만 강제되지 않습니다.

---

## 책 삭제

- Library Item 삭제 시 관련 기록도 함께 제거됩니다.
- 복구는 불가능하므로 신중히 진행하십시오.
