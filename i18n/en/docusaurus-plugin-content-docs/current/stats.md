# Stats

The `Stats` tab gives you a quick summary of accumulated reading activity.

## What it currently shows

- total reading time
- completed books count
- daily reading time for the last 7 days

## Last 7 days chart

The last 7 days section visualizes daily reading time as bars. If there is no recent data, the app shows an empty state message instead.

## When it is useful

- when you want to see how much you actually read this week
- when you want a quick count of completed books
- when you want to check whether your reading rhythm is continuing
